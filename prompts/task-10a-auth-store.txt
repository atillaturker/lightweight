==================================================
CONTEXT
==================================================

The app uses Firebase Auth as the identity provider. Three sign-in
methods must be supported:
1. Email + password
2. Google Sign-In (via @react-native-google-signin/google-signin)
3. Apple Sign-In (via expo-apple-authentication)

After successful sign-in, the user's profile is written to a Zustand
store persisted in MMKV. Firebase Auth session itself uses Firebase's
own persistence (already configured in services/firebase/config.ts).

export type AuthStatus = 'idle' | 'loading' | 'authenticated' | 'error';

export interface AuthUser {
  uid: string;
  email: string | null;
  displayName: string | null;
  photoURL: string | null;
  provider: 'password' | 'google.com' | 'apple.com';
}

export interface AuthState {
  status: AuthStatus;
  user: AuthUser | null;
  error: string | null;
}

export interface SignUpCredentials {
  email: string;
  password: string;
  displayName: string;
}

export interface SignInCredentials {
  email: string;
  password: string;
}

==================================================
services/authService.ts
==================================================

Wraps Firebase Auth. All functions are async and return AuthUser or
throw a normalized Error with a clear message.

Exports:

  signUpWithEmail(credentials: SignUpCredentials): Promise<AuthUser>
  signInWithEmail(credentials: SignInCredentials): Promise<AuthUser>
  signOut(): Promise<void>
  getCurrentUser(): AuthUser | null
  subscribeToAuthChanges(cb: (user: AuthUser | null) => void): () => void

On error, translate common Firebase error codes to human-readable
strings:
- auth/invalid-email        -> "That email doesn't look right."
- auth/user-not-found       -> "No account found with that email."
- auth/wrong-password       -> "Incorrect password."
- auth/email-already-in-use -> "An account with this email already exists."
- auth/weak-password        -> "Password must be at least 8 characters."
- auth/network-request-failed -> "Check your connection and try again."
- anything else             -> "Something went wrong. Please try again."

==================================================
services/googleSignIn.ts
==================================================

Wraps @react-native-google-signin/google-signin.

Exports:

  configureGoogleSignIn(): void
  signInWithGoogle(): Promise<AuthUser>
  signOutGoogle(): Promise<void>

configureGoogleSignIn reads the web client ID from
process.env.EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID. If missing, log a warning
and skip configuration.

signInWithGoogle:
1. Checks Play Services availability (Android only)
2. Gets the user's ID token
3. Signs into Firebase with GoogleAuthProvider.credential(idToken)
4. Returns AuthUser

==================================================
services/appleSignIn.ts
==================================================

Wraps expo-apple-authentication.

Exports:

  isAppleSignInAvailable(): Promise<boolean>
  signInWithApple(): Promise<AuthUser>

On iOS only — on Android the function throws an Error with message
"Apple Sign-In is not available on this platform."

signInWithApple:
1. Requests an Apple credential with full name and email scope
2. Extracts identityToken
3. Signs into Firebase with OAuthProvider('apple.com').credential()
4. Returns AuthUser

==================================================
store/authStore.ts
==================================================

Zustand store with persist to MMKV. Only `user` is persisted — status
and error reset to idle/null on app start.

State shape (from types.ts AuthState).

Actions:
  setStatus(status: AuthStatus): void
  setUser(user: AuthUser | null): void
  setError(error: string | null): void
  reset(): void

Export:
  export const useAuthStore = create<...>()(persist(...))

persist config:
  name: 'auth'
  storage: createJSONStorage(() => zustandStorage)
  partialize: (state) => ({ user: state.user })
  onRehydrateStorage: () => (state) => { if (state) state.status = 'idle'; }

==================================================
hooks/useAuth.ts
==================================================

  export function useAuth(): {
    user: AuthUser | null;
    status: AuthStatus;
    isAuthenticated: boolean;
    isLoading: boolean;
  }

  Uses useShallow on selectors.

  Also: on mount, subscribes to Firebase auth changes via
  subscribeToAuthChanges. On change, updates the store. Returns an
  unsubscribe cleanup.

  Also: on mount, calls configureGoogleSignIn() once.

==================================================
hooks/useSignInActions.ts
==================================================

  export function useSignInActions(): {
    signInEmail: (c: SignInCredentials) => Promise<void>;
    signUpEmail: (c: SignUpCredentials) => Promise<void>;
    signInGoogle: () => Promise<void>;
    signInApple: () => Promise<void>;
    signOut: () => Promise<void>;
  }

Each action:
1. Sets status to 'loading'
2. Calls the corresponding service
3. On success: setUser(user), setStatus('authenticated'), clear error
4. On error: setError(message), setStatus('error')
5. Never throws to the caller

signOut clears both Firebase session and the local store.
