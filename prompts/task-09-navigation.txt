==================================================
SCOPE
==================================================

The navigation must:

1. Switch between three root states based on auth + onboarding:
   - Not authenticated      -> AuthStack
   - Authenticated, not onboarded -> OnboardingStack
   - Authenticated, onboarded     -> MainTabs

2. MainTabs has four tabs: Today / Progress / History / Profile.
   Each tab owns its own native stack.

3. Auth screens (SignUp, LogIn) come from features/auth/screens/.
   These do NOT exist yet. Create minimal placeholder screens for now
   that render a title and a single button labeled "Continue". The real
   screens are built in Task 10.

4. Onboarding screens do NOT exist yet. Create minimal placeholder
   screens for all 5 steps. The real screens are built later.

5. All other screens (HomeToday, ActiveWorkout, etc.) do NOT exist yet.
   Create minimal placeholder screens so navigation compiles and runs.

The goal: after this task, the app boots, shows a tab bar, and can
navigate between placeholder screens. Real screen content comes in
subsequent tasks.

==================================================
ROOT NAVIGATOR
==================================================

Use NativeStackNavigator. headerShown false for all stacks — every
screen draws its own header via ScreenHeader component.

RootNavigator:

  const { isAuthenticated, hasOnboarded } = useAuthState();
  return (
    <Stack.Navigator screenOptions={{ headerShown: false }}>
      {!isAuthenticated ? (
        <Stack.Screen name="Auth" component={AuthStack} />
      ) : !hasOnboarded ? (
        <Stack.Screen name="Onboarding" component={OnboardingStack} />
      ) : (
        <Stack.Screen name="Main" component={MainTabs} />
      )}
    </Stack.Navigator>
  );

PLACEHOLDER SCREENS
==================================================

Each placeholder screen must:

- Render a SafeAreaView (edges: top)
- Show a ScreenHeader with the screen title (showBack if it is a push screen)
- Render an EmptyState component with:
    title: "<Screen Name>"
    message: "Placeholder — implemented in a later task."

Use existing components from @components/EmptyState and
@components/ScreenHeader.

Example for HomeTodayScreen:

  import { SafeAreaView } from 'react-native-safe-area-context';
  import { View, StyleSheet } from 'react-native';
  import { ScreenHeader } from '@components/ScreenHeader';
  import { EmptyState } from '@components/EmptyState';
  import { colors } from '@theme';

  export function HomeTodayScreen() {
    return (
      <SafeAreaView style={styles.container} edges={['top']}>
        <ScreenHeader title="Today" />
        <View style={styles.body}>
          <EmptyState
            title="Home"
            message="Placeholder — implemented in a later task."
          />
        </View>
      </SafeAreaView>
    );
  }

  const styles = StyleSheet.create({
    container: { flex: 1, backgroundColor: colors.canvas },
    body: { flex: 1, justifyContent: 'center' },
  });

Apply this pattern to every placeholder screen.

APP.TSX UPDATE
==================================================

Replace the Playground entry with the real navigation:

  import { GestureHandlerRootView } from 'react-native-gesture-handler';
  import { SafeAreaProvider } from 'react-native-safe-area-context';
  import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
  import { NavigationRoot } from '@/app/navigation';
  import { StatusBar } from 'expo-status-bar';

  const queryClient = new QueryClient({
    defaultOptions: {
      queries: {
        staleTime: 60_000,
        retry: 1,
      },
    },
  });

  export default function App() {
    return (
      <GestureHandlerRootView style={{ flex: 1 }}>
        <SafeAreaProvider>
          <QueryClientProvider client={queryClient}>
            <NavigationRoot />
            <StatusBar style="auto" />
          </QueryClientProvider>
        </SafeAreaProvider>
      </GestureHandlerRootView>
    );
  }
